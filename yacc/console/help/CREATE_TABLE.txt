NAME
    CREATE TABLE - This command is a shorthand for [ALTER DISTRIBUTION ATTACH
    TABLE](#alter-distribution-attach-table). It creates a table and attaches it
    to a distribution in a single statement.

SYNTAX
    CREATE [DISTRIBUTED] TABLE [schema.]<table_name> (<keys>)
      [IN <distribution_id> | FOR DISTRIBUTION <distribution_id>]
    CREATE [DISTRIBUTED] TABLE [schema.]<table_name>
      HASH [FUNCTION] <hashFunction> (<column_name> <type>)
      [IN <distribution_id> | FOR DISTRIBUTION <distribution_id>]

    where hashFunction is one of: MURMUR, CITY
    where type is one of: INT, INTEGER, UINTEGER, VARCHAR, UUID

DESCRIPTION
    This command is a shorthand for [ALTER DISTRIBUTION ATTACH
    TABLE](#alter-distribution-attach-table). It creates a table and attaches it
    to a distribution in a single statement.
    The `DISTRIBUTED` keyword is optional and has no effect on the behavior.

    There are three syntax forms for specifying distribution keys:

    **Parenthesized syntax** — column names and optional hash functions are
    listed inside parentheses.

    **Hash syntax** — a hash function is followed by one typed column in
    parentheses. The column type must correspond to the distribution column
    type, for example `INT` for `INTEGER HASH`.

EXAMPLES
    Simple column with no hash function (uses default distribution):
        CREATE TABLE r (i);
    Column with hash function:
        CREATE TABLE r HASH MURMUR (i INT);
    Attach to a specific distribution:
        CREATE TABLE t (id) IN ds1;
    Using FOR DISTRIBUTION syntax:
        CREATE DISTRIBUTED TABLE table1 HASH MURMUR (i INT)
          FOR DISTRIBUTION ds1;
    Composite key with multiple columns:
        CREATE TABLE t3 (id HASH MURMUR, id2 HASH MURMUR) IN ds3;
    Routing expression syntax for composite keys with typed columns:
        CREATE TABLE tr (MURMUR [id1 UINTEGER, id2 VARCHAR]);
    Schema-qualified table name:
        CREATE DISTRIBUTED TABLE sh1.r (i) IN d;
    DISTRIBUTION KEY syntax:
        CREATE DISTRIBUTED TABLE xx DISTRIBUTION KEY col1, col2
          HASH FUNCTION MURMUR IN ds1;
    Composite key without hash using DISTRIBUTION KEY syntax:
        CREATE DISTRIBUTED TABLE copy_test (id1, id2) IN ds2;

NOTES
    - **DISTRIBUTION KEY syntax** — uses explicit `DISTRIBUTION KEY` clause:
      `CREATE [DISTRIBUTED] TABLE [schema.]<table_name> DISTRIBUTION KEY <keys>
      [IN <distribution_id> | FOR DISTRIBUTION <distribution_id>]`
